# STM32F103 按键控制项目说明文档

## 项目概述

本项目是一个基于 STM32F103 的按键输入控制程序，实现了通过按键控制 LED 和蜂鸣器的功能。

---

## 编译错误分析

### 错误现象

```
undefined reference to `led_init'
undefined reference to `beep_init'
undefined reference to `key_init'
undefined reference to `key_scan'
```

### 错误原因

1. **链接器找不到函数定义**：虽然在 `main.c` 中调用了 `led_init()`、`beep_init()`、`key_init()` 和 `key_scan()` 函数，但这些函数的实现文件（`led.c`、`beep.c`、`key.c`）没有被添加到 CMake 的编译列表中。

2. **CMake 配置不完整**：`cmake/stm32cubemx/CMakeLists.txt` 中的 `MX_Application_Src` 变量只包含了基本的源文件，缺少外设驱动的源文件。

### 解决方案

在 `cmake/stm32cubemx/CMakeLists.txt` 文件中添加缺失的源文件：

```cmake
# STM32CubeMX generated application sources
set(MX_Application_Src
    ${CMAKE_CURRENT_SOURCE_DIR}/../../Core/Src/main.c
    ${CMAKE_CURRENT_SOURCE_DIR}/../../Core/Src/stm32f1xx_it.c
    ${CMAKE_CURRENT_SOURCE_DIR}/../../Core/Src/stm32f1xx_hal_msp.c
    ${CMAKE_CURRENT_SOURCE_DIR}/../../Core/Src/led.c      # 添加 LED 驱动
    ${CMAKE_CURRENT_SOURCE_DIR}/../../Core/Src/beep.c     # 添加蜂鸣器驱动
    ${CMAKE_CURRENT_SOURCE_DIR}/../../Core/Src/key.c      # 添加按键驱动
    ${CMAKE_CURRENT_SOURCE_DIR}/../../Core/Src/sysmem.c
    ${CMAKE_CURRENT_SOURCE_DIR}/../../Core/Src/syscalls.c
    ${CMAKE_CURRENT_SOURCE_DIR}/../../startup_stm32f103xe.s
)
```

## 硬件引脚配置

### LED 配置

- **LED0**：GPIOB Pin 5（推挽输出，上拉）
- **LED1**：GPIOE Pin 5（推挽输出，上拉）

### 蜂鸣器配置

- **BEEP**：GPIOB Pin 8（推挽输出，上拉）

### 按键配置

- **KEY0**：GPIOE Pin 4（输入模式，上拉）
- **KEY1**：GPIOE Pin 3（输入模式，上拉）
- **WKUP**：GPIOA Pin 0（输入模式，下拉）

## 程序实现逻辑

### 1. 主程序流程（main.c）

```c
int main(void)
{
    uint8_t key;
    
    // 系统初始化
    HAL_Init();                    // HAL 库初始化
    SystemClock_Config();          // 配置系统时钟（72MHz）
    MX_GPIO_Init();               // GPIO 基础初始化
    
    // 外设初始化
    led_init();                    // LED 初始化
    beep_init();                   // 蜂鸣器初始化
    key_init();                    // 按键初始化
    LED0(0);                       // 点亮 LED0
    
    // 主循环
    while (1)
    {
        key = key_scan(0);         // 扫描按键
        
        if (key)
        {
            switch (key)
            {
                case WKUP_PRES:    // WKUP 按键按下
                    BEEP_TOGGLE(); // 蜂鸣器状态翻转
                    break;
                    
                case KEY1_PRES:    // KEY1 按键按下
                    LED1_TOGGLE(); // LED1 状态翻转
                    break;
                    
                case KEY0_PRES:    // KEY0 按键按下
                    LED0_TOGGLE(); // LED0 状态翻转
                    LED1_TOGGLE(); // LED1 状态翻转
                    break;
            }
        }
        else
        {
            HAL_Delay(10);         // 延时 10ms
        }
    }
}
```

### 2. LED 驱动实现（led.c）

```c
void led_init(void)
{
    GPIO_InitTypeDef gpio_init_struct;
    
    // 使能时钟
    LED0_GPIO_CLK_ENABLE();
    LED1_GPIO_CLK_ENABLE();
    
    // 配置 GPIO
    gpio_init_struct.Pin = LED0_GPIO_PIN;
    gpio_init_struct.Mode = GPIO_MODE_OUTPUT_PP;   // 推挽输出
    gpio_init_struct.Pull = GPIO_PULLUP;           // 上拉
    gpio_init_struct.Speed = GPIO_SPEED_FREQ_HIGH; // 高速
    HAL_GPIO_Init(LED0_GPIO_PORT, &gpio_init_struct);
    
    gpio_init_struct.Pin = LED1_GPIO_PIN;
    HAL_GPIO_Init(LED1_GPIO_PORT, &gpio_init_struct);
    
    // 初始状态：熄灭
    LED0(1);
    LED1(1);
}
```

### 3. 蜂鸣器驱动实现（beep.c）

```c
void beep_init(void)
{
    GPIO_InitTypeDef gpio_init_struct;
    
    // 使能时钟
    BEEP_GPIO_CLK_ENABLE();
    
    // 配置 GPIO
    gpio_init_struct.Pin = BEEP_GPIO_PIN;
    gpio_init_struct.Mode = GPIO_MODE_OUTPUT_PP;   // 推挽输出
    gpio_init_struct.Pull = GPIO_PULLUP;           // 上拉
    gpio_init_struct.Speed = GPIO_SPEED_FREQ_HIGH; // 高速
    HAL_GPIO_Init(BEEP_GPIO_PORT, &gpio_init_struct);
    
    // 初始状态：关闭
    BEEP(0);
}
```

### 4. 按键驱动实现（key.c）

```c
uint8_t key_scan(uint8_t mode)
{
    static uint8_t key_up = 1;  // 按键释放标志
    uint8_t keyval = 0;
    
    if (mode) key_up = 1;       // 支持连按模式
    
    // 检测按键按下
    if (key_up && (KEY0 == 0 || KEY1 == 0 || WK_UP == 1))
    {
        HAL_Delay(10);          // 消抖延时
        key_up = 0;
        
        // 判断具体哪个按键
        if (KEY0 == 0)  keyval = KEY0_PRES;
        if (KEY1 == 0)  keyval = KEY1_PRES;
        if (WK_UP == 1) keyval = WKUP_PRES;
    }
    // 检测按键释放
    else if (KEY0 == 1 && KEY1 == 1 && WK_UP == 0)
    {
        key_up = 1;
    }
    
    return keyval;
}
```

## 按键功能说明

| 按键 | 功能 | 按键值 |
|------|------|--------|
| **WKUP** | 切换蜂鸣器状态（开/关） | WKUP_PRES (3) |
| **KEY1** | 切换 LED1 状态（亮/灭） | KEY1_PRES (2) |
| **KEY0** | 同时切换 LED0 和 LED1 状态 | KEY0_PRES (1) |

### 按键扫描特点

1. **消抖处理**：按键按下后延时 10ms 消除机械抖动
2. **防连击**：默认模式下，必须释放按键后才能再次触发
3. **优先级**：同时按下多个按键时，按 WK_UP > KEY1 > KEY0 的优先级处理

## 技术要点

### 1. HAL 库使用

- 使用 STM32 HAL 库进行硬件抽象
- 通过 `HAL_GPIO_Init()` 初始化 GPIO
- 使用 `HAL_GPIO_WritePin()` 和 `HAL_GPIO_TogglePin()` 控制输出
- 使用 `HAL_GPIO_ReadPin()` 读取输入状态

### 2. 系统时钟配置

- 外部晶振（HSE）：8MHz
- PLL 倍频系数：9 倍
- 系统时钟（SYSCLK）：72MHz
- AHB 总线：72MHz
- APB1 总线：36MHz（2 分频）
- APB2 总线：72MHz（1 分频）

### 3. GPIO 配置要点

- **推挽输出**（OUTPUT_PP）：适用于 LED 和蜂鸣器
- **上拉输入**（PULLUP）：KEY0、KEY1（默认高电平，按下为低）
- **下拉输入**（PULLDOWN）：WKUP（默认低电平，按下为高）

### 4. 代码优化

- 移除了所有冗余注释，提高代码可读性
- 统一使用 `HAL_Delay()` 函数，无需额外的 delay 库
- 头文件路径简化，便于项目移植

## 常见问题

### Q1: 编译时找不到函数定义？

**A**: 确保在 `cmake/stm32cubemx/CMakeLists.txt` 中的 `MX_Application_Src` 变量包含了所有 .c 源文件。

### Q2: 烧录时提示找不到 .elf 文件？

**A**: 检查文件名是否正确，编译生成的文件名应该与项目名一致（本项目为 `press.elf`）。

### Q3: 按键按下没有反应？

**A**: 
1. 检查 GPIO 引脚配置是否正确
2. 检查按键电路连接
3. 检查按键扫描函数中的引脚读取逻辑

### Q4: LED 不亮或常亮？

**A**:
1. 检查 LED 电路极性
2. 确认初始化代码中的 LED 状态设置
3. 检查 GPIO 推挽输出配置
